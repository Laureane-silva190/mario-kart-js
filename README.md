# 🏎️ Mario Kart.js - Desafio DIO

Simulador de corrida de Mario Kart utilizando Node.js, desenvolvido para a Formação Node.js da DIO.

## 🛠️ Tecnologias Utilizadas
- **Node.js** (Ambiente de execução)
- **JavaScript ES6+**
- **Async/Await** para controle de fluxo

## 🎮 Funcionalidades
- Escolha de personagens com atributos únicos (Velocidade, Manobrabilidade, Poder).
- Sistema de dados aleatórios.
- Blocos dinâmicos: **Reta** (Velocidade), **Curva** (Manobrabilidade) e **Confronto** (Poder).
- Lógica de pontuação e decremento de pontos em confrontos.

## 🚀 Como executar
1. Clone este repositório.
2. Certifique-se de ter o Node.js instalado.
3. No terminal, execute:
   ```bash
   node index.js
